# GSE227122: Supplementary Cross-Lineage Ecotype Transfer

This directory contains the scripts and derived tables used to process the **GSE227122 pediatric leukemia cohort** for strict cross-lineage projection within the **Ecotype–Lévy–OU–Branching** framework.

Unlike the discovery (GSE235063) and external AML calibration (GSE235923) cohorts, GSE227122 is **not** used in the primary therapy-aware relapse analyses. Instead, it serves as a supplementary robustness analysis that evaluates whether the diagnosis-anchored ecological scaffold remains interpretable when transferred to an independent pediatric leukemia cohort.

The workflow emphasizes **annotation, frozen-space projection, and cross-cohort comparison** under a fixed transferred reference rather than reconstruction of a new ecological or latent disease-state framework.

---

## Analytical role

Within the repository, GSE227122 provides a **supplementary cross-lineage transfer analysis**.

The workflow evaluates whether the ecological organization learned from the primary discovery cohort remains coherent after transfer to an external pediatric leukemia dataset.

Because this cohort contains only **one relapse sample**, it is **not used in the primary relapse-dynamics analyses** presented in the main manuscript.

Instead, the outputs support:

- Supplementary Figure S7
- Supplementary Data 5

---

## Workflow overview

The workflow proceeds through five major stages:

1. ingestion and quality control of the GSE227122 dataset;
2. cell annotation and marker-based summary generation;
3. projection into the frozen diagnosis-anchored ecological scaffold;
4. comparison of projected ecological organization across samples and longitudinal states;
5. generation of compact summary tables and visualization files for supplementary analyses.

These analyses support:

- transparent reporting of the strict transfer workflow;
- reproducible reuse of annotation and projection outputs;
- evaluation of cross-lineage transferability of the diagnosis-anchored scaffold.

## Key outputs

The principal outputs generated by this workflow include:

- **gse227122_projected_sample_scores.csv**  
  Sample-level projected disease-state and ecological scores.

- **gse227122_projected_samples_with_optional_programs.csv**  
  Projected scaffold variables together with optional program summaries.

- **cross_cohort_reference_table.csv**  
  Mapping between discovery-cohort reference variables and transferred GSE227122 variables.

- **cross_cohort_ecotype_summary_stats.csv**  
  Cohort-level summaries used to assess transfer consistency.

- **gse227122_dx_eoi_paired_pc_deltas.csv**  
  Longitudinal paired changes within the transferred ecological space.

## Interpretation

This workflow should be interpreted as a **strict transferability analysis**, not an independent discovery analysis.

The ecological scaffold is **not relearned** using GSE227122.

Instead, samples are projected into the diagnosis-anchored reference learned from GSE235063, allowing assessment of whether the transferred ecological organization remains biologically coherent across cohorts.

Because GSE227122 contains only one relapse sample, the dataset is unsuitable for robust therapy-aware relapse modeling and is therefore used exclusively as supplementary evidence supporting the transferability of the ecological scaffold.

## Reproducibility notes

The scripts assume that the required GSE227122 input matrices and the corresponding GSE235063 frozen reference objects have already been downloaded or generated.

Users should update local file paths in the configuration blocks before execution.

Recommended execution order:

```text
01_ingest_gse227122.py
02a_annotate_gse227122_cells.py
03_project_gse227122_ecotype_transfer.py
04_compare_gse227122_transfer.py
05_plot_gse227122_strict_transfer_compact.py
```
