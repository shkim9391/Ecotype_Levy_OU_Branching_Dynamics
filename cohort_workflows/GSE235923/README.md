# GSE235923: External AML Calibration and Frozen-Space Projection

This directory contains the scripts, derived tables, and reference projection files used to process the **GSE235923 pediatric AML cohort** as the **external calibration cohort** within the **Ecotype–Lévy–OU–Branching** framework.

Unlike the primary discovery cohort (GSE235063), this dataset is **not** used to construct the diagnosis-anchored disease-state scaffold. Instead, all samples are projected into the frozen discovery scaffold to evaluate whether the learned disease-state organization generalizes to an independent pediatric AML cohort without relearning the latent representation.

The repository is organized to maximize **transparency, reproducibility, and modularity** while remaining lightweight. Large intermediate objects and rendered figure files are not distributed directly because they can be regenerated from the provided scripts and publicly available source data.

---

## Analytical role

Within the overall workflow, GSE235923 is responsible for:

- construction of the external calibration cohort;
- harmonization of clinical metadata;
- transfer of reference annotations from GSE235063;
- frozen-space projection into the diagnosis-anchored disease-state scaffold;
- computation of sample-level dynamic summaries;
- independent evaluation of treatment-aware disease-state organization.

The projected variables generated here are subsequently used in the manuscript workflow to produce the external validation analyses presented in **Figure 6** and portions of **Figure 7**.

---

## Workflow overview

The workflow proceeds through five major stages:

1. construction and harmonization of the external cohort manifest;
2. building the pediatric AML calibration cohort;
3. transfer of reference labels and annotation from the GSE235063 discovery cohort;
4. projection into the frozen diagnosis-anchored disease-state scaffold;
5. generation of sample-level calibration tables and cross-cohort summaries.

The repository includes:

- executable analysis scripts;
- harmonized cohort manifests;
- transferred annotation summaries;
- projected disease-state coordinates;
- ecological and malignant-state summaries;
- calibration tables.

**Calibration summaries**

- `gse235923_dx_secondary_calibration_table.csv`

These outputs summarize the transferred disease-state organization and support comparison with the primary discovery cohort.

- `primary_ecotype_pca_reference_scores.csv`
- `primary_ecotype_pca_loadings.csv`

These files define the frozen projection model applied to the external cohort.

## Interpretation

This directory contains the **external calibration workflow**.

The diagnosis-anchored disease-state scaffold is **not reconstructed** using GSE235923.

Instead, the external cohort is projected into the frozen discovery scaffold learned from GSE235063, allowing direct comparison of diagnosis, treatment-response, remission, and relapse states within a shared disease-state reference frame.

This strategy provides an independent evaluation of the transferability of the diagnosis-anchored scaffold without introducing cohort-specific latent representations.

## Reproducibility notes

Scripts assume that the required GSE235923 input files and the corresponding frozen reference objects from GSE235063 have already been generated.

Users should update local file paths before execution.

The recommended execution order follows the numbered script directories:

```text
01_manifest/
02_build/
03_transfer/
04_projection/
05_figures/
```

The projected outputs generated here are subsequently incorporated into the manuscript workflow under:

```text

Multimodal_OU_Levy_Branching_Scaffold/
```
