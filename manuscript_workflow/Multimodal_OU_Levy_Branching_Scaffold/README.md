## Statistical analyses

Independent-group comparisons were performed using two-sided Mann–Whitney U tests.

Matched diagnosis-to-relapse comparisons were performed using two-sided Wilcoxon signed-rank tests.

Cliff’s delta was calculated for independent-group effect-size summaries.

Displayed P values are unadjusted. Formal tests were restricted to prespecified phase-level and transition-class contrasts.

## Reproducibility

The manuscript workflow was implemented using scripted Python analyses.

The repository includes:

* figure-generation scripts,
* intermediate sample-level and interval-level tables,
* statistical summary files,
* frozen projection outputs,
* workflow manifests,
* and manuscript-linked supplementary data.

Large raw and controlled-access datasets are not redistributed in this repository. Public accession numbers and preprocessing instructions are provided in the cohort-specific README files.
